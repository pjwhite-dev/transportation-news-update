Owner sign-in

Sign in with a GitHub token for the site owner's account. GitHub confirms whose token it is; nothing else on this page opens without it.

Making the token (once)
  1. On GitHub, open Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Repository access: Only select repositories, then transportation-news-update.
  3. Permissions: Issues, Read and write. Nothing else.
  4. Generate it, copy it, and paste it above. The token stays in this browser; it is sent only to GitHub.
